## 目标

让第一次进入仓库的偏前端全栈开发者在约十分钟内建立当前最小可行产品心智模型，并能沿一条真实任务从 Next.js 接口追到 PostgreSQL、BullMQ、工作进程、LangGraph、终态事务与服务端推送，而不需要先阅读六十余份历史迭代。

## 本轮范围

- 在主链核心文件补充设计意图与不变量注释，重点覆盖任务与事务发件箱同事务、至少投递一次、租约与隔离令牌、检查点重放、服务端推送事件日志与生产组合入口；
- 为根目录、网页端、工作进程、数据库、共享契约、工作流、智能体、模型、供应商与检查点建立一致的职责和阅读入口；
- 纠正包内说明文件中“尚未接入生产工作进程”等过期描述；
- 保留现有部署、最小权限与验证说明，不改变运行时行为。

## 注释原则

- 解释“为什么需要这一层”和“破坏后会出现什么失败”，不重复函数名或语法；
- 只在跨进程边界、事务不变量、恢复语义和安全边界处添加认知锚点；
- 详细操作留在说明文件和运维手册，代码注释保持局部可读；
- 解释性正文与代码注释统一使用中文，文件名、命令、环境变量和代码标识保持原样。

## 范围外

- 不修改业务逻辑、数据库数据结构、环境变量或部署状态；
- 不恢复长期记忆产品路径；
- 不补齐所有历史实验包的文档；
- 不执行 Vercel 或服务器密钥写入。
